# SkyHunt

느리지만 잘 도는 비행기와 빠르지만 잘 못 도는 미사일이 맞붙는 1:1 추격전입니다. 한 명은 비행기, 한 명은 미사일을 맡고, 2라운드에 역할을 바꿔 격추 수로 승부합니다. 방 번호로 인터넷 대전을 하거나 봇과 겨룹니다.

**플레이:** https://woomars.github.io/skyhunt/

개인 재미를 위한 비상업 프로젝트입니다. 코드와 직접 만든 그림은 MIT 라이선스([LICENSE](LICENSE))이고, 그 밖의 자료는 아래에 적은 각 라이선스와 권리를 따릅니다. 소리는 Web Audio로 직접 합성했고, 그림은 코드로 그렸습니다.

## English

**SkyHunt** — a slow plane that turns well vs. a fast missile that doesn’t: a 1-on-1 chase. Swap roles in round 2; most kills wins. Play online by room number or against bots.

**Play:** https://woomars.github.io/skyhunt/

A personal, non-commercial project. Code and original artwork are under the MIT License ([LICENSE](LICENSE)); everything else follows the licenses and rights listed above. Online play uses PeerJS (with webrtc-adapter, sdp, eventemitter3 and peerjs-js-binarypack bundled in). All sounds are synthesized and all graphics are drawn in code. Full license texts of the bundled libraries: [THIRD_PARTY_LICENSES.txt](THIRD_PARTY_LICENSES.txt).
